# Book Catalog

## Task: [https://drive.google.com/](https://drive.google.com/file/d/1RBRcuH-_oAvtjem5Xs0c4NXZ8I38aYyH/view)

## How to run the app

Install dependencies:

```bash
npm install
```

### Development mode

Start the development server:

```bash
npm run dev
```

### Production build

Create an optimized production build:

```bash
npm run build
```

## Project structure

### api/

Contains files for API requests and external data.

### assets/icons/

Contains SVG icons used in the application.

### components/

Contains files responsible for creating and rendering UI components.

### components/main/

Contains components used in the main application area.

### services/

Contains application logic for working with books and favorites.

### states/

Contains functions for rendering different application states, such as loading, errors, empty results, and favorites.

### styles/

Contains CSS files for application styles.

### utils/

Contains reusable helper functions.

### main.js

The main entry point of the application.
